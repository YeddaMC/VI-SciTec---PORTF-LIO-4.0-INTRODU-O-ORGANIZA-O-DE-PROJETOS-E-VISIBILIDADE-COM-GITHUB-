🚀 TUTORIAL PASSO A PASSO

1. Criar sua conta no GitHub

1.1 Acesse o GitHub

Acesse o site do GitHub e clique em Sign up.

1.2 Informe seu e-mail

Digite seu e-mail e avance.

1.3 Crie sua senha

Escolha uma senha forte.

1.4 Escolha seu nome de usuário (username)

Escolha com atenção: este nome fará parte do endereço do seu perfil e dos seus projetos na web (ex: github.com/seu-usuario).

1.5 Valide a verificação de segurança

Resolva o desafio do robô.

1.6 Confirme o código de verificação

Insira o código enviado para o seu e-mail.

2. Criar seu Profile README (seu cartão de visitas)

Compare o visual de um perfil com e sem o Profile README:

2.1 Abra o menu do seu perfil e clique em "Your repositories"

2.2 Clique em "New" para criar um novo repositório

2.3 Defina as configurações especiais do repositório

Em Repository name, digite exatamente o mesmo nome do seu nome de usuário (username).

Marque as opções:

  • Public
  • Add a README file

2.4 Edite o README do seu perfil

Clique no ícone de lápis ou no botão Edit para personalizar a sua apresentação.

Exemplo de Modelo de Texto em Markdown para usar no seu perfil:

# 👋 Olá, eu sou o [Seu Nome]

- 🎓 Estudante / Pesquisador(a) na instituição [Sua Instituição]
- 🎯 Interessado(a) em [Suas Áreas de Interesse]
- 🚀 Atualmente trabalhando no projeto [Nome do Projeto]
- 📫 Como me encontrar: [Seu E-mail / LinkedIn / Redes]

---
### 🛠️ Tecnologias e Ferramentas
- Markdown / GitHub / HTML / CSS

2.5 Salve as alterações

Clique no botão verde Commit changes... e confirme.

3. Criar um repositório para o seu projeto acadêmico ou pessoal

3.1 Clique em "New" para criar outro repositório

Siga para a criação do repositório de um projeto específico.

3.2 Dê um nome simples e descritivo

Exemplo: projeto-scitec-2026 ou sistema-monitoramento.

3.3 Marque "Public" e "Add a README file"

Clique em Create repository.

4. Estruturar o README do projeto

4.1 Edite o README.md do projeto com as informações principais

Modelo de estrutura sugerido:

# 📌 Nome do Projeto

## 📖 Sobre o Projeto
Breve resumo sobre o objetivo do projeto.

## 👥 Autores e Orientadores
- **Autor(a):** [Seu Nome](https://github.com/seu-usuario)
- **Orientador(a):** [Nome do Orientador]

## 🛠️ Tecnologias Utilizadas
- Tecnologia 1
- Tecnologia 2

## 🔗 Links Úteis
- [Documentação na Wiki](link-da-wiki)

5. Criar e organizar a Wiki do projeto

5.1 Clique na aba "Wiki" no menu do seu repositório

5.2 Clique em "Create the first page"

5.3 Escreva o conteúdo complementar da documentação e salve

5.4 Copie o link (URL) da Wiki criada

6. Conectar a Wiki e os Projetos ao seu Profile README

6.1 Abra o arquivo README.md do seu repositório do perfil

6.2 Adicione os links dos seus repositórios e projetos

Utilize a sintaxe de link em Markdown: [Texto do Link](URL).

7. Publicar uma página web com o GitHub Pages

7.1 Vá em "Settings" no seu repositório de código/site

7.2 No menu lateral, clique em "Pages"

7.3 Selecione a branch "main" e salve

Em Source, selecione a branch main, pasta / (root) e clique em Save.

8. Resultado Final do Ecossistema Integrado

Após concluir todos os passos, seu perfil apresentará seus projetos, documentação organizada via Wiki e seu site publicado pelo GitHub Pages!
