📚 1. Introdução: O que são o Git e o GitHub?

O GitHub

O GitHub é uma plataforma que permite hospedar, organizar, documentar, compartilhar e colaborar em projetos, inclusive em projetos open source (código aberto), nos quais o código é disponibilizado para que outras pessoas possam conhecer, utilizar, modificar e contribuir com o projeto, de acordo com suas regras de licença e colaboração.

Um dos principais recursos do GitHub são os repositórios, que funcionam como espaços onde um projeto pode ser armazenado, desenvolvido e apresentado. Além de armazenar repositórios, o GitHub oferece recursos para organização, documentação, colaboração, automação e publicação de projetos.

Neste workshop da VI SciTec, utilizaremos principalmente:

  • Perfil: conta de usuário na plataforma.
  • Profile README: apresentação personalizada no perfil.
  • Repositório: espaço onde o projeto será armazenado e apresentado.
  • README: apresentação e documentação inicial do projeto.
  • Wiki: documentação complementar.
  • Markdown: formatação dos textos.
  • Links: conexão entre perfil, projeto e documentação.

🛠️ Recursos e Ferramentas Disponíveis na Plataforma

  • GitHub Projects (Kanban): quadros visuais para organizar tarefas, prazos e o fluxo de trabalho de maneira rastreável.
  • Gerenciamento de Colaboradores: Permite convidar outras pessoas para editar, revisar e construir o projeto juntos.
  • GitHub Actions: automação de fluxos de trabalho (builds, testes, deploys).
  • Pipelines e DevOps: Fluxos automatizados que preparam e colocam o sistema para rodar.
  • GitHub Pages (Hospedagem): Publicação gratuita de sites, portfólios e páginas direto a partir dos seus arquivos.
  • GitHub Codespaces (IDE em Nuvem): Um ambiente completo de desenvolvimento que abre no navegador.
  • Gráficos de Linhas de Código (Insights): Painel estatístico do projeto.
  • Métricas de Produtividade (Pulse): Resumo estatístico do ritmo de desenvolvimento.
  • Contribuição em Projetos Open Source: Permite colaborar diretamente com códigos abertos no mundo todo.

O Git

O Git é um programa que roda direto no seu computador. Ele funciona como uma máquina do tempo para os arquivos do seu trabalho. Cada vez que você faz uma gravação, o Git cria um Commit (uma foto do estado atual).

💡 Nota do Nosso Minicurso: Como o nosso objetivo na VI SciTec é documentar a produção acadêmica diretamente no GitHub, nós não vamos usar o Git no computador hoje, mas é fundamental que você conheça a existência dele.

🔄 GitHub + Git

Como os integrantes e os computadores se comunicam? (Push e Pull)

  • ⬆️ Push (Empurrar / Enviar): Envia as alterações da sua máquina para o repositório remoto na internet (GitHub).
  • ⬇️ Pull (Puxar / Trazer): Baixa as atualizações do GitHub na internet para o seu computador.

🕒 Curiosidades

O caos do "Trabalho_Final_Versao99_AgoraVai.docx"

Antes dos sistemas de controle de versão distribuídos, organizar arquivos entre várias pessoas era um pesadelo de arquivos salvos com nomes diferentes por e-mail. O Git e o GitHub surgiram para resolver essa confusão.
